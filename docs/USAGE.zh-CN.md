# 双设备版使用指南

## 新旧版本

- 原来的“启动定位工具.app”仍打开单设备版。
- 新的“双设备定位工具.app”打开双设备版，不覆盖原入口。
- 两个版本的路线草稿分别保存。切换版本时先退出正在使用的那个版本。

双设备分发包内，“双设备定位工具.app”和“Route Studio Dual.app”应放在同一文件夹。Mac 需要 Apple Silicon、macOS 15+；两台手机都要开启开发者模式。此 App 为本地签名，未经过 Apple 公证；若系统拦截首次打开，请核实来源并按 macOS 对该应用的许可提示处理。

## 连接两台

1. 退出单设备版，用两根支持数据传输的数据线将两台 iPhone 连接到 Mac。
2. 分别解锁手机，在提示时选择“信任此电脑”。手机能充电不代表已建立 USB 数据连接。
3. 启动双设备版，刷新设备，在通道 A、B 中各选一台不同的 iPhone。
4. 连接两台，等待两端都就绪。首次开发镜像准备可能需要联网；两台准备会依次通过共享镜像缓存的检查，之后独立运行。

设备不能同时分配给两个通道。回放、固定位置或恢复未确认时，先在该通道结束并恢复，再切换设备。界面会显示实际连接的手机，请核对名称。

## 路线和配速

点击顶部通道卡片，切换当前地图与编辑器。每个通道独立保存路线与配速，切换查看不会停止后台运行的另一台。

可以分别绘制或导入两条路线，设置不同配速；同一路线使用两台时，可将当前通道路线复制到另一个空闲通道，再分别调整配速。复制路线不会复制运行进度或启动定位。

首次默认路线为 1000 米地图描线示例，默认配速 06:00 分钟/公里。JSON 保存路线与设置；GPX 导入使用轨迹形状，配速由当前通道界面决定。文件和设备定位使用 WGS84，国内高德底图保持坐标校准开启。

## 开始和结束

- 单通道控制只影响当前通道；暂停一台时另一台继续。
- 一起开始要求两台都连接就绪、路线有效并且目标不同；两条路线可以不同。
- 一起开始会紧接着向两台发送命令，不保证毫秒级同时。若其中一台启动失败，会结束这次组合启动并尝试恢复两台。
- 全部结束会分别发送恢复真实定位指令。请在两台手机地图核对实际位置。
- 路线完成时该通道自动尝试恢复，另一通道按自己的进度继续。
- USB 断开时该通道显示异常；重连原手机并恢复定位。另一台保持独立。
- 正常退出会分别处理两台恢复，未确认的结果会提示处理。

## 排查

| 现象 | 处理 |
| --- | --- |
| 只显示一台 | 检查第二台的数据线、USB 接口、解锁和信任状态，分别单独接入确认 |
| 提示旧版本正在运行 | 退出原单设备版，再在双设备版连接 |
| 提示设备已占用 | 检查其他双设备版进程或另一通道是否已使用该手机 |
| 整条路线偏移数百米 | 结束回放，核对底图校准和文件坐标系，先用固定点核对 |
| 开始按钮不可用 | 核对连接、有效路线、当前处理状态和恢复结果 |
| 意外断线或强制退出 | 重连对应手机并恢复真实定位，必要时重启手机后在地图核对 |
| 入口找不到主程序 | 完整解压并将两个 App 放回同一文件夹 |

每个通道有独立日志。反馈问题时提供对应通道、系统版本和错误信息，去除设备标识及其他个人信息。
