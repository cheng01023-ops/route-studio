# 使用指南

## 准备

成品 App 面向 M 系列 Mac，macOS 15 或以上。下载完整 `RouteStudio-Mac.zip` 并解压，保留“启动定位工具.app”和“Route Studio.app”在同一文件夹，双击中文入口即可打开。

安装包内置 Python 组件。预编译版本为本地签名，未经过 Apple 公证；首次打开若被系统拦截，请核实来源并按 macOS 对该应用的许可提示处理。

## 连接和开始

1. 用支持数据传输的 USB 线连接 iPhone，解锁并信任 Mac。
2. 开启 iPhone“设置 → 隐私与安全性 → 开发者模式”，按手机提示完成重启与确认。若选项尚未出现，可先用 Xcode 的设备窗口与手机配对。
3. 启动工具。单台 USB iPhone 会自动连接；多台设备时请选择目标再连接。首次准备开发镜像可能需要联网和等待。
4. 顶部显示“USB 已就绪”后，确认路线、距离和配速，再点击“开始”。连接和载入路线本身不会启动回放。
5. 暂停会冻结回放进度；继续后从暂停位置移动。点“结束并恢复定位”可提前结束。
6. 路线完成或正常退出后会尝试发送恢复真实定位指令。请在手机地图确认实际位置。

## 路线与配速

首次载入一条 1000 米的地图描线示例，默认配速 `06:00` 分钟/公里，预计 6 分钟。以后会恢复本机上次编辑的路线与配速。

在地图中点击添加途经点，拖动标记调整位置。右侧可排序、删除或撤销。闭合路线会把末点连回起点，并允许设置循环圈数。地图路线不会自动贴合道路，弯道需要足够的途经点。

- **JSON** 保存点位、配速、闭合状态和圈数，适合保存或迁移自己的路线。
- **GPX** 导入使用轨迹形状，回放配速由工具界面决定。导出包含按当前配速生成的时间戳。
- 支持一条连续 GPX 轨迹、路线或一组航点；多段轨迹请先拆分。
- 选择点后可设置固定位置；结束固定位置使用后请恢复真实定位。
- 不接手机也可以运行离线预览，检查路线形状与预计时长。

## 坐标校准

文件和设备定位统一为 WGS84。国内高德底图显示和选点需转换 GCJ-02，保持工具栏“国内高德底图校准”开启；国际 Apple 底图下可关闭。

如果整体偏移数百米，请先结束回放并恢复定位，核对底图设置和文件坐标系，再使用一个固定点进行校准。地图描线距离与其他应用的采样、过滤或距离统计可能存在差异。

## 常见问题

| 现象 | 检查内容 |
| --- | --- |
| 未发现手机 | 数据线、手机解锁、信任提示，然后刷新设备 |
| 连接失败 | 开发者模式、信任状态、网络及开发镜像准备提示，处理后重试 |
| 开始按钮不可点 | 路线是否有效、设备是否就绪、是否正在处理其他操作 |
| 其他应用位置不刷新 | 先在手机地图核对，再检查该应用的定位权限与前台状态 |
| USB 断开或强制退出 | 重连后恢复真实定位，或重启 iPhone，再在手机地图核对 |
| 中文入口找不到主程序 | 将两个 App 放回同一文件夹或重新完整解压 |

运行日志入口位于应用底部。提交问题时请提供错误与复现步骤，并去除设备标识、账号和其他个人信息。
