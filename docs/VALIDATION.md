# 验证范围

发布前执行以下检查：

- Python 路线距离、配速、闭合多圈、重复点、跨 180° 经线和坐标转换。
- 暂停时钟、预览与设备隔离、恢复失败处理、完成与停止恢复、并发命令拒绝。
- Swift JSON/GPX 往返、XML 转义、距离计算与多段轨迹拒绝。
- 启动默认路线、草稿与配速恢复、空/损坏草稿处理、地图设置、单设备连接与多设备选择。
- 打包组件冷启动、自检、分发 ZIP 完整性、可执行权限、相对符号链接和本地签名。

此前已在 iOS 27.0.1 开发设备验证 USB 连接、固定点校准、1000 米 / 6 分钟路线回放及清除模拟定位指令。此结果不代表所有设备、系统小版本或第三方应用均兼容。

公开仓库包含源码、测试、原始图标与人工生成的示例路线。本机配对记录、设备日志、对话记录和个人验证反馈不作为发布内容。
